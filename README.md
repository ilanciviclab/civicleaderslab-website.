# Civic Leaders Lab website

The public website for civicleaderslab.org. Plain HTML and CSS, no build step needed.

- The pages are the `.html` files in this folder. `styles.css` holds the look.
- `_source/build.py` regenerates every page from one place: `python3 _source/build.py .`
- Hosting: connect this repository to Netlify or Cloudflare Pages with no build command and `.` as the publish folder.
